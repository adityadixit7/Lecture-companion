SETTINGS

AI connection

Use a stable free/local model first. This extension can fall back between Ollama, OpenRouter, and Gemini.

Preferred AI provider

For the most stable long-term setup, use a local Ollama model. If you do not want local hosting, choose OpenRouter or Gemini.

Ollama (local free model)

Run Ollama locally and pull a vision model such as qwen2.5vl:7b or llama3.2-vision.

OpenRouter

Optional. Use for cloud fallback with small vision models. Free availability changes often.

Gemini API key

Create a key in Google AI Studio. Free-tier limits can change. The key is stored in this Chrome profile's local extension storage.

Privacy / cost note

Your captured slide and prompt are sent to the selected AI provider. For the most stable long-term setup, prefer a local Ollama model. The extension does not create billing by itself.

Watcher mode checks the visible tab every five seconds and sends a slide to AI only when the image changes. Pause it whenever you want. No teacher audio is captured by this extension.
